# ATS-Recruitment-Funnel-Analysis

Analysis of an ATS recruitment funnel focused on:

- identifying recruitment funnel bottlenecks
- comparing effectiveness across different roles
- evaluating the functionality of the candidate assessment system

## Tools

- Power Query
- Power BI
- Microsoft Word

## Deliverables

- Data preparation and transformation
- Interactive Power BI analysis
- Analytical report

The dataset was provided for a recruitment case study and was anonymized.
